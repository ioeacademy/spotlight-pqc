# Disclaimer

**Spotlight PQC is an educational simulator.** It exists to help people practise Cisco IOS XE
commands and become familiar with post-quantum VPN concepts (IKEv2, ML-KEM, PPK) and the
order of the configuration steps. Please read this before using it.

## What it is — and what it isn't

- **For learning only.** It is a teaching aid, not a network tool.
- **Not a real router.** The command line and its output are a model written in JavaScript.
  Output, defaults, error messages and behaviour **may differ** from real Cisco platforms and
  software releases, and some features are simplified or missing.
- **Do not use it to validate configurations.** A configuration that works in the simulator is not
  proven to work, or to be secure, on real equipment. Don't use it to design, test, certify or
  troubleshoot production networks, or to assess security.
- **Always check the official documentation** (Cisco configuration guides and release notes) and
  test on real equipment, in a lab, before deploying anything.
- **Example values are for the lab only.** Pre-shared keys, PPKs and addresses in the tutorials
  are teaching values and must never be reused in a real network.
